🌟 GlowUp – Skincare E-Commerce Frontend Project
🛍️ Project Overview
GlowUp is a fully responsive Arabic-language e-commerce website for skincare products, developed using HTML5, CSS3, and JavaScript. The project features a modern and elegant design tailored to RTL (Right-to-Left) direction, ensuring a smooth and intuitive shopping experience on all screen sizes.

🎯 Objective
To showcase my frontend development skills by building a complete and professional user interface for a skincare store — ideal for clients looking for RTL websites, responsive design, and attractive product presentation.

🧱 Project Structure
Homepage: Hero section, featured products, store benefits, customer reviews, newsletter signup.

Product List Page: All products with filtering and search options.

Product Details Page: Full product info with image, description, and add-to-cart feature.

Shopping Cart: Interactive cart with quantity adjustment and local storage support.

Checkout Page: Form for shipping and payment with validation.

About & Contact Pages: Store background and contact form.

⭐ Key Features
✅ 100% Arabic + RTL support

✅ Responsive layout for desktop, tablet, and mobile

✅ Clean and modern UI tailored for skincare aesthetics

✅ Interactive shopping cart using localStorage

✅ Form validation for checkout and contact

✅ Organized and maintainable code (CSS Variables, ES6 Functions)

🛠️ Technologies Used
HTML5 – semantic and accessible structure

CSS3 – with CSS Variables, Flexbox, Grid, and Media Queries

JavaScript (ES6+) – for dynamic interactions and cart logic

🔧 Customization & Scalability
Easily update colors via CSS variables

Add products by duplicating the product card component

Ready for future upgrades: authentication, real payments, database integration, admin panel, multi-language/currency support
